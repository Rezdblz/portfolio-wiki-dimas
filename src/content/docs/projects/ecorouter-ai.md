## Overview

EcoRouter AI picks a route with the help of a language model. Input arrives as structured JSON, the model answers as structured JSON, and the result is a route recommendation the caller can act on.

## My role

Full-Stack / AI Engineer, July 2026 — I built the project independently, end to end.

## What I built

- The routing system in Python, calling OpenAI-compatible LLM APIs.
- A Dockerized task-processing pipeline with structured JSON input and output.
- Configurable environments, so the same image runs against different API endpoints and settings.

## Stack

Python · OpenAI-compatible LLM APIs · Docker
